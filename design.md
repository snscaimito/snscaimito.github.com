# Website Design

The site must always be responsive. Every page and component must adapt to the available viewport width across phones, tablets, and desktops.

- Use the available width on larger screens; do not leave desktop content confined to a narrow mobile layout.
- Prefer flexbox with wrapping and flexible sizing. Stack content when the available space no longer supports a readable layout.
- Include borders and padding in component sizing so columns fit alongside their gaps.
- Keep text, images, navigation, and controls readable and usable without clipping or unintended horizontal scrolling.
- Use width constraints only for a concrete readability or functional reason.
- Verify layout changes at narrow, intermediate, and wide viewport widths, including around affected breakpoints.
